Упрощённые схемы пайплайна для слайдов аудиторской презентации (файлы *_auditor_ru.drawio).
Они повторяют логику технических диаграмм pipeline_01–05, но без имён кода, аббревиатур и деталей реализации — только понятные шаги на русском языке.
Откройте файлы в draw.io (diagrams.net) или вставьте на слайд PowerPoint через «Вставка → Рисунок».
